# อ้างอิง Dashboard EA (ตามภาพ)

## แถวหลัก

| แสดงผล | ความหมาย | ใช้ตัดสินใจ |
|--------|----------|-------------|
| `Mode: SINGLE` | เทรดชุดปกติ ไม่ไล่ recovery | ปลอดภัยกว่า RECOVERY |
| `Mode: RECOVERY` | กำลังเพิ่มไม้แก้ขาดทุน | เสี่ยงสูง — จับตา equity |
| `Signal: BUY/SELL/NONE` | ทิศทางที่ระบบเลือก | ควรตรงกับออเดอร์เปิด |
| `Spread: 280` | สเปรดปัจจุบัน (points) | สูง = ยากกำไร |
| `ATR: 2.406` | ความผันผวน | ต่ำมาก = ตลาดนิ่ง |
| `Velocity: 606.0 pts` | ความเร็วราคา | สูง = burst — มักเข้าใกล้ๆ นี้ |
| `TickRate: 2.60` | ความถี่ tick | ต่ำ = สภาพคล่องต่ำ |

## Score

| แสดงผล | ความหมาย |
|--------|----------|
| `Score BUY: 3` | คะแนนฝั่งซื้อ |
| `Score SELL: 5` | คะแนนฝั่งขาย — **สูงกว่า = สัญญาณขาย** (ตัวอย่างภาพ) |

## การจัดการออเดอร์

| แสดงผล | ความหมาย |
|--------|----------|
| `BUY Lots / SELL Lots` | ปริมาณเปิดแต่ละฝั่ง |
| `Positions` | จำนวนออเดอร์เปิด |
| `Recovery: 0` | ขั้น recovery ปัจจุบัน |
| `Basket: -0.30` | กำไร/ขาดทุนลอยตัวรวม |
| `Target: 3.00` | เป้าปิดทั้งกลุ่ม ($) |

## ฟิลเตอร์

| แสดงผล | ความหมาย |
|--------|----------|
| `ChopLock: OFF` | ไม่บล็อกตลาดไซด์เวย์ |
| `EquityStop: OK` | ยังไม่โดนหยุด equity |

## BTC v3.01 (เพิ่มเติม)

| แสดงผล | ความหมาย |
|--------|----------|
| `TrendBias(PERIOD_M15): DOWN` | เทรนด์ M15 ฝั่งลง |
| `SigGate: FORCE_FLOW` | ใช้ gate แรง |
| `FootprintMode: AUTO` | โหมด footprint อัตโนมัติ |
| `Engine: AGGRESSIVE` | เข้าแบบรุนแรง |
