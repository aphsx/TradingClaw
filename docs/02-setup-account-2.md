# ขั้นที่ 2 — บัญชี Exness Cent #2 (คนละ Server)

ตามภาพ: บัญชีซ้าย `Exness-MT5Real20` / บัญชีขวา `Exness-MT5Real37`

## 2.1 เปิดบัญชีที่สอง

1. Exness Personal Area → **Open new account**
2. ประเภท: **Cent** + **MT5** (เหมือนบัญชี #1)
3. **สำคัญ:** เลือกหรือขอ **Server คนละตัว** กับบัญชี #1
   - ถ้า PA ให้เลือก server ตอนสร้าง → เลือกตัวที่ไม่ซ้ำ (เช่น Real37 ถ้าตัวแรก Real20)
   - ถ้าไม่มีตัวเลือก → ติดต่อ support Exness ขอเปลี่ยน server หรือเปิดบัญชีใหม่ที่ region/server อื่น
4. จด Login, Password, **Server name** บัญชี #2

## 2.2 เปิด MT5 หน้าต่างที่สอง

เลือกวิธีใดวิธีหนึ่ง:

### วิธี A — คอมเดียวกัน (Windows)

1. เปิด MT5 อีกครั้งจาก shortcut (หรือ copy โฟลเดอร์ terminal แยก instance)
2. Login ด้วยบัญชี **#2**
3. ตั้งชื่อหน้าต่างให้จำง่าย เช่น `MT5-Real37`

### วิธี B — คอมสองเครื่อง

- เครื่อง 1: บัญชี #1
- เครื่อง 2: บัญชี #2

### วิธี C — Mac

- มักต้องใช้ terminal แยกหรือ VM — ถ้าเปิด instance เดียวได้แค่ login สลับ → ใช้สลับบัญชีชั่วคราวได้ แต่ไม่ตรงภาพ 2 หน้าต่างพร้อมกัน

## 2.3 ตั้งค่าเหมือนบัญชี #1

บัญชี #2 ทำครบ:

- [ ] Algo Trading **เขียว**
- [ ] Market Watch: symbol `c` ชุดเดียวกัน
- [ ] Chart `XAUUSDc` **M15** เปิดไว้

## 2.4 ทำไมต้อง 2 server (ตามภาพ)

| แนวทาง | ความหมาย |
|--------|----------|
| รัน EA เหมือนกันทั้งคู่ | กำไรสะสม 2 พอร์ต (เห็น History คนละยอด) |
| เปรียบ tick | server ที่ราคามาก่อน → EA อีกฝั่ง “ตาม” (ถ้า EA รองรับหรือตั้ง manual) |

**ไม่ต้อง VPS** — แค่เปิด 2 MT5 พร้อมกันที่บ้าน
