# ขั้นที่ 5 — รัน Demo + สังเกต (1–2 สัปดาห์)

เป้าหมาย: เข้าใจว่า EA **เข้าเมื่อไหร่ / ปิดเมื่อไหร่ / RECOVERY บ่อยแค่ไหน** ก่อนใส่เงิน Real

## 5.1 ตั้งค่า Demo

- ใช้บัญชี **Demo Cent** ทั้ง #1 และ #2 (หรืออย่างน้อยบัญชีที่จะใช้ Real)
- Lot **0.01**, Basket **3.00** — เหมือน Real
- เปิด chart ที่จะใช้จริง (อย่างน้อย XAUUSDc M15 ทั้ง 2 บัญชี)

## 5.2 สิ่งที่ต้องดูทุกวัน

### บน Dashboard EA

| ค่า | คำถามที่ต้องตอบได้ |
|-----|-------------------|
| **Velocity** | เข้าไม้ตอน Velocity สูงจริงไหม? |
| **TickRate** | ช่วง tick หนาแน่นไหม? |
| **Score BUY / SELL** | ฝั่งไหนชนะก่อนเข้า? |
| **Signal** | ตรงกับทิศทางออเดอร์ไหม? |
| **Mode SINGLE / RECOVERY** | เปลี่ยน RECOVERY บ่อยแค่ไหน? |
| **Basket / Target 3.00** | ปิดรวมที่ $3 หรือปิดทีละไม้? |
| **Spread** | เข้าตอน spread กว้างเกินไหม? |

### ในแท็บ History

- กำไรต่อไม้ประมาณเท่าไหร่ ($0.5–$3 ตามภาพ?)
- มี SL แน่น (คอลัมน์ S/L สีแดง) ไหม
- จำนวนไม้ต่อวัน

## 5.4 เกณฑ์ “พร้อม Real” (แนะนำ)

| เกณฑ์ | เป้า |
|-------|------|
| รัน demo | ≥ 7 วัน |
| เข้าใจ SINGLE vs RECOVERY | อธิบายได้เอง |
| Basket ปิดที่ $3 | เห็นบ่อยพอสมควร |
| Drawdown demo | รู้ว่าแย่สุดวันละเท่าไหร่ |
| 2 บัญชี | EA ไม่ error บ่อยทั้งคู่ |

ถ้า RECOVERY บ่อยและขาดทุนสะสม → **อย่าใส่ Real** จนกว่าจะลด Recovery level ใน EA หรือปิด Recovery

## 5.5 เปรียบ 2 server (ตามภาพ 1)

วันหนึ่งนั่งดู 5–10 นาที:

1. เปิด XAUUSDc M15 คู่ขนาน 2 หน้าต่าง
2. ดูราคา bid/ask — ฝั่งไหนขยับก่อนเมื่อมีข่าวหรือช่วง volatile
3. จดว่า EA เข้าทั้งสองฝั่งพร้อมกันหรือห่างกันกี่วินาที

ไม่บังคับวิเคราะห์ลึก — แค่เข้าใจว่าทำไมคนใช้ 2 server
