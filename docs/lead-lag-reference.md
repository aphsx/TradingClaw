# Lead-Lag อ้างอิง (ภาพ 3) — ไม่บังคับถ้า EA ไม่มี feed

ลิสต์จากภาพ: เรียงตามความเป็นไปได้

| ลำดับ | คู่ | ความหมายสั้นๆ |
|------|-----|----------------|
| 1 | GC → XAUUSD | ฟิวเจอร์ทอง COMEX นำ → ทอง spot โบรก |
| 2 | DXY → EURUSD | ดัชนีดอลลาร์นำ → ยูโร |
| 3 | Oil → USDCAD | น้ำมันนำ → ดอลลาร์/แคนาดา |
| 4 | XAU → USDJPY | ทองนำ → เยน |
| 5 | BTC → NAS100 | บิทคอยน์นำ → Nasdaq |
| 6 | SI → XAGUSD | ฟิวเจอร์เงินนำ → เงิน spot |

## ใช้ทำอะไร

- **อ่าน chart คู่ขนาน** บน TradingView (leader) + MT5 Exness (follower)
- เมื่อ leader กระโดดแรง แต่ follower ยัง — บางที EA จะเข้า burst ตามทิศทางนั้น
- **ไม่ต้องเขียนโปรแกรม** ถ้า EA ที่ซื้อคำนวณจากราคา MT5 อย่างเดียว

## บน Exness มักมี

- `XAUUSDc`, `XAGUSDc`, `EURUSDc`, `USDJPYc`, `BTCUSDc`

## มักไม่มีตรงชื่อ (ดูที่อื่น)

- GC, SI (futures), DXY, NAS100, Crude — ใช้ TradingView หรือ terminal อื่นเป็นจอนำ

## กับแผนหลัก (EA only)

ทำครบ 2 บัญชี + EA ก่อน — ลิสต์นี้เป็น **ความรู้เสริม** ไม่ใช่ขั้นต้นบังคับ
