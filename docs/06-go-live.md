# ขั้นที่ 6 — Real ทุน $100–200

ทำเมื่อ Demo ผ่านเกณฑ์ใน [05-demo-observation.md](05-demo-observation.md)

## 6.1 ก่อนฝากเงิน

- [ ] เข้าใจ **RECOVERY** — ยอมรับว่าอาจล้าง $200 ได้ใน 1–2 วัน
- [ ] ตั้ง **EquityStop / Max daily loss** ใน EA (ถ้ามี)
- [ ] Lot ยัง **0.01** — อย่าเพิ่ม lot เพราะทุนเล็ก
- [ ] Basket Target ยัง **3.00**

## 6.2 ฝากและสลับบัญชี

1. Exness PA → ฝาก **$100–200** ต่อบัญชี (หรือรวมที่ยอมเสียได้)
2. MT5 → login บัญชี **Real Cent** (ไม่ใช่ Demo)
3. ตรวจชื่อ server ตรงกับที่จด (Real20 / Real37)
4. แปะ EA ใหม่ทุก chart (บางที Inputs reset หลังเปลี่ยนบัญชี)

## 6.3 เปิดเทรดทีละขั้น

| วัน | แนะนำ |
|-----|--------|
| 1–3 | Real แค่ **XAUUSDc** บัญชีเดียว, 1 chart |
| 4–7 | เพิ่มบัญชี #2 ทอง หรือเพิ่ม EURUSDc |
| หลัง 7 | เพิ่ม chart ตาม [04-multi-charts.md](04-multi-charts.md) |

## 6.4 การจัดการทุน $100–200

| รายการ | แนะนำ |
|--------|--------|
| ทุนต่อบัญชี | $50–100 ถ้าเปิด 2 บัญชี mirror |
| Max open positions | ตาม EA default — อย่าเพิ่ม recovery steps |
| หยุดเทรด | ขาดทุนรวมวันนี้ -$30 ถึง -$50 (กำหนดเอง) |
| ถอนกำไร | ถอนเมื่อถึงเป้า เช่น +$50 — อย่าปล่อยทบในพอร์ตเล็ก |

## 6.5 สิ่งที่ broker อาจทำ

- ขยาย spread ช่วงข่าว
- Requote / slippage
- ถามแหล่งที่มา EA ถ้าเทรดถี่มาก

## 6.6 Checklist วันแรก Real

- [ ] Algo Trading เขียว
- [ ] บัญชี Real (ไม่ใช่ Demo)
- [ ] Lot 0.01 ทุก chart
- [ ] ดูแท็บ Experts ไม่มี error ซ้ำ
- [ ] จด equity เริ่มต้น: $________

## 6.7 เมื่อผิดแผน

1. ปิด Algo Trading (ปุ่มแดง) ทันที
2. ปิดออเดอร์มือในแท็บ Trade ถ้าจำเป็น
3. กลับไป Demo ปรับ Inputs
4. อย่าเพิ่ม lot เพื่อ “ไล่ขาดทุน”
